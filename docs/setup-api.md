# Подключение Wildberries и запуск «Торпеды»

Инструкция для Windows. Всё делается один раз, дальше — две команды для запуска.

## 1. Создать два ключа в кабинете WB

Ключи создаются в кабинете продавца: профиль (правый верхний угол) → раздел **«Интеграции по API»**
(в старых версиях кабинета — «Настройки» → «Доступ к API») → **«Создать токен»**.
Названия разделов WB иногда меняет; если не нашли, ищите по слову «API» в настройках профиля.

**Ключ 1 — только чтение** (для загрузки данных). Отметьте категории:

- Контент
- Цены и скидки
- Статистика
- Аналитика
- Продвижение (пригодится для рекламы позже)
- Тарифы (если такая категория есть в списке)

и обязательно поставьте галочку **«Только на чтение»**.

**Ключ 2 — для изменения цен.** Отметьте **только** категорию **«Цены и скидки»**,
галочку «Только на чтение» **не** ставьте.

Так ключ для данных ничего не может изменить в кабинете, а ключ для цен не видит остальное.

Скопируйте каждый ключ сразу после создания: WB показывает его один раз.
Никому не пересылайте ключи, в том числе в чат.

## 2. Установить программы

1. **uv** — запускает Python-часть приложения. Откройте PowerShell (Пуск → «PowerShell») и выполните:

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

   Закройте и снова откройте PowerShell.

2. **Код приложения.** Проще всего установить [GitHub Desktop](https://desktop.github.com/),
   войти в аккаунт и клонировать репозиторий `stumul9300/torpeda1`, например в папку `C:\torpeda1`.
   Обновлять код потом — кнопкой «Fetch origin» / «Pull».

## 3. Положить ключи

1. В папке `C:\torpeda1\backend` найдите файл `.env.example`.
2. Скопируйте его рядом и назовите копию `.env` (без `.example`).
3. Откройте `.env` в Блокноте и вставьте ключи после знака `=`:

   ```
   WB_API_TOKEN=ключ_только_чтение
   WB_PRICES_TOKEN=ключ_для_цен
   ```

4. Сохраните. Этот файл остаётся только на вашем компьютере: он в списке исключений
   и в GitHub не попадёт.

## 4. Проверить связь с WB

В PowerShell:

```powershell
cd C:\torpeda1\backend
uv sync
uv run python -m torpeda.sync check
```

Должно получиться так:

```
Контент: ok
Цены и скидки: ok
Статистика: ok
Тарифы: ok
Календарь акций: ok
```

Если где-то ошибка 401 — у ключа не включена эта категория: создайте ключ заново с нужными галочками.

## 5. Загрузить данные

```powershell
uv run python -m torpeda.sync all
```

Загружаются товары, цены, комиссии, остатки FBO, заказы, продажи, финансовые отчёты за 30 дней и акции.
Первый раз это может занять несколько минут: WB ограничивает частоту запросов, программа ждёт сама.
В конце покажется, сколько строк загружено в каждом разделе.

## 6. Запустить приложение

```powershell
uv run uvicorn torpeda.api.app:app
```

и откройте в браузере <http://127.0.0.1:8000/docs>. Пока это служебная страница со всеми методами
(можно нажать на метод → «Try it out» → «Execute»). Таблица с интерфейсом будет в следующем обновлении.

Остановить — `Ctrl+C` в окне PowerShell.

## Как устроена отправка цен

1. В таблице вы вводите новую цену или скидку — это «расчётная цена», в WB она не уходит.
2. «Предпросмотр» показывает по каждому товару: было → станет, маржу до и после.
3. Отправка в WB происходит только после подтверждения именно этого предпросмотра.
   Если цена в WB успела поменяться, отправка отменится и попросит открыть предпросмотр заново.
4. Каждая отправка записывается в журнал. Из журнала можно вернуть прежнюю цену — тоже через предпросмотр.
