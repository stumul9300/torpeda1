# Как запустить «Торпеду» (Windows)

## Один раз

1. **Скачать программу.** Войдите на github.com под своим аккаунтом, откройте репозиторий
   `stumul9300/torpeda1`, нажмите зелёную кнопку **Code** → **Download ZIP**.
   Распакуйте архив, например в `C:\torpeda1`.
   (Удобнее обновлять через [GitHub Desktop](https://desktop.github.com/): File → Clone repository.)

2. **Запустить.** В папке программы дважды щёлкните **`start.bat`**.
   В первый раз он сам установит всё нужное (пару минут), потом откроет программу в браузере.
   Чёрное окно не закрывайте, пока пользуетесь программой.

3. **Вставить ключи.** Программа сама откроется на вкладке «Настройки».
   Вставьте ключи в поля и нажмите «Сохранить ключи» — сразу пройдёт проверка связи с WB.

4. **Загрузить данные.** Кнопка «Загрузить из WB» справа вверху.

Дальше каждый раз — только двойной щелчок по `start.bat`.

## Обновление программы

Дважды щёлкните **`update.bat`**. Он откроет скачивание новой версии в браузере, сам распакует её поверх программы
и запустит. Если браузер сохранил ZIP не в «Загрузки», перетащите этот ZIP мышкой на `update.bat`.

Ключи, себестоимость, база и журнал цен лежат отдельно от программы, в папке `%LOCALAPPDATA%\Torpeda`
(путь виден внизу вкладки «Настройки»), поэтому обновление их не стирает.
Для страховки на вкладке «Настройки» можно скачать себестоимость в Excel и загрузить её обратно.

## Какие ключи создать в кабинете WB

Профиль (правый верхний угол) → **«Интеграции по API»** (в старых версиях кабинета — «Настройки» → «Доступ к API»)
→ **«Создать токен»**. WB показывает ключ один раз — скопируйте его сразу.

- **Ключ для данных**: категории Контент, Цены и скидки, Статистика, Аналитика (нужна для остатков FBO и FBS),
  Финансы (финотчёты и их итоги для сверки), Продвижение (реклама),
  Продвижение (и Тарифы, если есть в списке) и галочка **«Только на чтение»**.
- **Ключ для изменения цен**: только категория **«Цены и скидки»**, без галочки «Только на чтение».

Ключи хранятся только на вашем компьютере, в файле `%LOCALAPPDATA%\Torpeda\keys.json`, который не попадает в GitHub.
Никому их не пересылайте, в том числе в чат.

Если проверка связи показывает ошибку 401 у какого-то раздела — у ключа не включена эта категория.

## Как устроена отправка цен

1. В таблице вводите новую цену или скидку — сразу видна новая маржа. В WB это пока не уходит.
2. Кнопка «Отправить новые цены в WB…» открывает предпросмотр: было → станет и маржа до и после.
3. Цены уходят в WB только после **двойного щелчка** по красной кнопке в предпросмотре.
   Если цена в WB успела поменяться, отправка отменится и попросит открыть предпросмотр заново.
4. Все отправки видны во вкладке «Журнал цен», оттуда можно вернуть прежнюю цену — тоже через предпросмотр.

## Для разработки

Запасной способ задать ключи — файл `backend/.env` (см. `backend/.env.example`) или переменные окружения
`WB_API_TOKEN` и `WB_PRICES_TOKEN`; они важнее ключей из интерфейса.
Загрузка из командной строки: `uv run python -m torpeda.sync check` и `uv run python -m torpeda.sync all`.
