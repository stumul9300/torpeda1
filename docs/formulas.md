# Формулы «Торпеды»

Два расчёта: **плановая юнит-экономика** (для таблицы цен, «что будет при такой цене»)
и **фактическая прибыль** по финансовым отчётам WB (для аналитики, «что было»).
Оба сверены с «Ракетой» до копейки. Код: `backend/torpeda/calc/`.

Проценты везде числами от 0 до 100. Деньги считаются в `Decimal`, округление до копеек только при показе.

## 1. Плановая юнит-экономика (на одну проданную единицу)

| Обозначение | Что это |
| --- | --- |
| P0 | цена до скидки |
| d | скидка продавца, % |
| P = P0 × (1 − d) | цена продавца (цена поставщика) |
| k | комиссия WB по предмету, %: своя для FBO и FBS |
| a | эквайринг, % |
| t | налог, % от суммы продажи (сейчас 7%) |
| L | логистика на единицу (раздел 3) |
| R | реклама на единицу |
| S | хранение на единицу = ставка в день × дней |
| B | брак на единицу |
| C | себестоимость |

```
Комиссия  = P × k
Эквайринг = P × a
Налог     = P × t
Прибыль   = P − Комиссия − Эквайринг − Налог − L − R − S − B − C
ROI, %    = Прибыль / C × 100
Маржа, %  = Прибыль / P × 100
Убыточный: Прибыль < 0
```

СПП платит WB, на прибыль продавца она не влияет. Цена для покупателя
`P × (1 − СПП)` показывается справочно, в целых рублях.

Цена под целевую маржу m:

```
P  = (C + L + R + S + B) / (1 − k − a − t − m)
P0 = P / (1 − d)
```

## 2. Фактическая прибыль по финансовым отчётам

```
Маржа = К перечислению (продажи − возвраты, без компенсаций)
      + компенсация скидки по программе лояльности
      − баллы, удержанные по программе лояльности
      − стоимость участия в программе лояльности
      − логистика − хранение − платная приёмка − штрафы
      − брак − прочие удержания WB − реклама (нормированная)
      − налог − себестоимость − прочие наши затраты

ROI, %            = Маржа / себестоимость × 100
Маржинальность, % = Маржа / продажи в цене поставщика × 100
На единицу        = сумма / (продажи − возвраты, шт)
```

Сверено с отчётом «Ракеты» «Анализ детализации финансовых отчётов ВБ по складам и размерам»
(выгрузка 23.10.2026): совпадение во всех 9 892 строках, включая итог 27 685 842,71.

Заметка: в отчёте «Ракеты» процент эквайринга считается от продаж **с СПП**
(517 507,22 / 22 987 045,07 = 2,25%), а в калькуляторе применяется к цене продавца.

## 3. Логистика на единицу

Основной способ — по факту из отчётов (решение Ольги):

```
L = вся логистика товара за период / (продажи − возвраты, шт)
```

Для новых товаров без продаж — по тарифу и проценту выкупа b:

```
Туда     = (первый литр + доп. литр × (V − 1)) × коэффициент склада
L        = Туда / b + Обратно × (1 − b) / b
```

Пример «Ракеты»: 118,645 / 0,34 + 69,1 × 0,66 / 0,34 = 483,09.
