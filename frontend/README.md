# Интерфейс

Обычные HTML, CSS и JavaScript без сборки: FastAPI отдаёт эту папку на http://127.0.0.1:8000/.
Таблица — AG Grid Community 32.3.3, файлы лежат в `vendor/` (лицензия MIT), чтобы программа работала без интернета.
Все расчёты делает сервер (`backend/torpeda/calc`), интерфейс только показывает и отправляет ввод.
